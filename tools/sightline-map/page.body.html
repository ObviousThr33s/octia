Do vanilla landmarks point at each other?

No. Every structure start in the save falls on its own jittered grid: one start per cell, dropped somewhere in the first part of it. Different types use different cells and are independently salted, so they never relate to each other at all.

That is a spacing rule, not a route. Below, each start with the cell it landed in and its offset inside that cell. Distinct cells throughout, every offset inside the window the rule allows.

What Octia lays instead

A node every 512 blocks, wandering up to 96 from the middle of its cell, and — the part vanilla never does — a next node one cardinal step away. The segment between them is a leg: a line across the world with a direction along it. Each obelisk is a 3×5 andesite prism laid along the leg under its feet, with a slot bored down its length you can sight through.

Cardinal steps and never diagonal: two nodes a step apart wander independently, so the worst a leg bends is atan(2J / (SPACING − 2J)) — 31° at 96 against 512. Under 45°, so the cardinal a leg lies nearest is never in doubt. A diagonal step would sit exactly between two of them and the prism's long axis would be a coin toss.
